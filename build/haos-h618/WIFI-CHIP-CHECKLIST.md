# WiFi 芯片验证清单与量产选型

## AIC8801（当前手板）验证清单

> **实勘更新**：本板 AIC8801 是 **USB 形态**（`a69c:5721 aicsemi Aic MSC`），
> 上电默认枚举为 U 盘模式（AIC flash 1.7MB，即 sda）。驱动要先把 USB 从 MSC
> 切到 WLAN 才会出现 wlan0 —— 验证清单第一条就是这一步。
> AIC8800 驱动是**厂商树外驱动**（aic8800_bsp + aic8800_fdrv + 固件），不在主线。

- [ ] **USB 模式切换**：加载驱动后 `lsusb` 从 `a69c:5721 (MSC)` 变为 WLAN 接口 ID，
      `iw dev` 出 wlan0
- [ ] SDIO 探测：`dmesg | grep -i aic`，驱动加载无固件报错
- [ ] **STA 模式**：连接 2.4G/5G 路由器，iperf3 跑满带宽、掉电重连 24h 稳定
- [ ] **AP 模式（配网热点的前提）**：`nmcli device wifi hotspot ssid EasyHA-Setup`
      手机可连、DHCP 正常、配置页可达
      ⚠️ AIC8800D80 系已知问题：旧固件 2.4G AP 静默失效（不发 beacon），务必用新固件
- [ ] 开热点再切回 STA 的循环 ×20（我们的配网流程反复用到）
- [ ] 驱动随系统冷启动自动加载（module 加载顺序/固件路径 /lib/firmware/aic8800*）
- [ ] 国家域码 CN、功率合规（量产认证需要）
- [ ] 省电模式下的 latency（智能音箱/传感器场景敏感）
- [ ] 长稳：72h 老化 + 断电重启 100 次

> 任一项不过 → 走下面的量产替代。驱动维护成本要算长期账：每换一次内核版本，
> 树外驱动都要跟一次移植。

## 量产替代选型（全部主线内核驱动，零移植成本）

| 模组 | 接口 | 主线驱动 | AP 模式 | 备注 |
|---|---|---|---|---|
| **AP6256 / AP6236** | SDIO | brcmfmac（多年主线） | ✅ 稳 | 智能硬件最常见组合，首选 |
| **RTL8822CS** | SDIO | rtw88_8822cs | ✅ | 双频 WiFi5，国产板常见 |
| **RTL8723DS** | SDIO | rtw88_8723ds | ✅ | 单频 2.4G，低成本 |
| **MT7921AU** | USB | mt7921u | ✅ | WiFi6，USB 接口量产插拔方便 |

选型建议：**双频选 AP6256 或 RTL8822CS；极致成本选 RTL8723DS**。
换芯片时只需：删 `package/aic8800` 引用 → kernel 片段加对应驱动（brcmfmac/rtw88）
→ DTS 的 mmc1/供电脚按新模组改 → 重出镜像，其余全部不动。
